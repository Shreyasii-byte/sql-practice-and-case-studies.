# SQL Subqueries & CTEs 🔍

Practice exercises focused on advanced SQL querying and analytical problem-solving using MySQL.

### Topics Covered
- Nested and scalar subqueries
- Correlated subqueries
- EXISTS and NOT EXISTS
- Common Table Expressions (CTEs)
- WITH clause
- Customer spending analysis
- Monthly revenue analysis

### Dataset
Customer and order records from a fictional sales database.

### Skills Demonstrated
MySQL · Advanced SQL · Subqueries · CTEs · Data Analysis · Analytical Query Writing

**Goal:** Strengthen SQL skills for complex data analysis and Data Analyst interviews.
