# Customer Sales Analysis 📊

## Objective
Analyze fictional sales data using SQL to understand revenue, customer spending, city-wise performance, and monthly trends.

## Business Questions
- What is the total revenue?
- Who are the highest-spending customers?
- Which city generates the most revenue?
- What is the average order value?
- Which month has the highest revenue?

## Key Findings
- **Total revenue:** 21,500.00
- **Top customer:** Aarav — 5,700.00
- **Top city:** Delhi — 9,000.00
- **Average order value:** 2,687.50
- **Top revenue month:** February 2026 — 8,900.00

*These findings are based on fictional sample data.*

## Skills Demonstrated
MySQL · JOINs · Aggregate Functions · GROUP BY · ORDER BY · Date Functions
