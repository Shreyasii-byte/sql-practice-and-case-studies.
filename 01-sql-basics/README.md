# SQL Basics 🗄️

A collection of beginner-level SQL exercises focused on fundamental database querying and data retrieval using MySQL.

### 📚 Topics Covered
- SELECT and DISTINCT
- WHERE conditions
- AND and OR operators
- BETWEEN and IN
- LIKE and pattern matching
- ORDER BY and LIMIT
- Basic table creation and data insertion

### 📊 Dataset
A fictional employee dataset containing:
- Employee names
- Departments
- Salaries
- Cities

### 🛠️ Skills & Tools
MySQL · SQL Queries · Data Filtering · Data Retrieval · Sorting

### 🎯 Objective
Build a strong foundation in SQL for data analysis, database querying, and analytical problem-solving.

### 📁 File
- `sql_basics_practice.sql` — SQL queries covering fundamental concepts and practical exercises.
