# Pandas Fundamentals 🐼

Hands-on Python practice focused on data manipulation, exploration, and statistical analysis using Pandas and NumPy.

### Topics Covered
- Creating DataFrames
- Dataset exploration using head(), info(), describe()
- Handling missing values and duplicates
- Statistical analysis using Pandas
- Filtering and sorting data
- GroupBy and aggregation
- NumPy arrays and statistical operations

### Dataset
Fictional retail sales dataset containing customer, city, category, sales, and quantity information.

### Technologies
Python · Pandas · NumPy

**Goal:** Build a strong foundation in Python for Data Analytics and Machine Learning.
