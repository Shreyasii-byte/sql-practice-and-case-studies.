# SQL Basics 🗄️

This folder contains SQL practice exercises covering fundamental querying and data retrieval using MySQL.

### Topics Covered
- SELECT and DISTINCT
- WHERE and filtering conditions
- AND, BETWEEN, IN and LIKE
- ORDER BY and LIMIT
- Basic table creation and data insertion

### Dataset
A fictional employee dataset containing employee names, departments, salaries, and cities.

### Skills Practiced
MySQL · Data Filtering · Data Retrieval · Sorting · Query Writing

**Goal:** Build a strong SQL foundation for Data Analytics and AI/ML workflows.
