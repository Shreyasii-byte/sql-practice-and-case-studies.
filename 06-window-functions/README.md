# SQL Window Functions 📈

Practice exercises focused on advanced SQL analytics and analytical calculations using MySQL.

### Topics Covered
- ROW_NUMBER()
- RANK() and DENSE_RANK()
- PARTITION BY
- Running totals using SUM() OVER()
- LAG() for previous-row comparisons
- Combining CTEs with window functions

### Dataset
Customer and order records from a fictional sales database.

### Skills Demonstrated
MySQL · Window Functions · Analytical SQL · Ranking · Trend Analysis · Data Analysis

**Goal:** Develop advanced SQL skills for analytical reporting and Data Analyst interviews.
