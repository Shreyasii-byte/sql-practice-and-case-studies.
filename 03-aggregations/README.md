# SQL Aggregations 📊

Practice exercises focused on summarizing and analyzing datasets using MySQL aggregate functions.

### Topics Covered
- COUNT(), SUM(), AVG()
- MIN() and MAX()
- GROUP BY
- HAVING
- Department-wise and city-wise analysis

### Dataset
Employee records containing salaries, departments, and cities.

### Skills Demonstrated
MySQL · Data Aggregation · Statistical Summaries · Group Analysis · Analytical SQL

**Goal:** Develop SQL skills for extracting meaningful insights from structured datasets.
